네트워크 정보 (ws2_32.lib), Windows OS 마스터 (windows.h), IP 버전 독립적 네트워크 기능 (ws2tcpip.h), 차세대 네트워크 인터페이스 API (netioapi.h)<br><br>

인터페이스 (iphlpapi.lib) - 네트워크 인터페이스 수, 인터페이스 연결 상태, 인터페이스 속도<br>
네트워크 주소 (iphlpapi.lib) - Ipv4, 서브넷, 게이트웨이, mac, dns<br>
네크워크 성능 (iphlpapi.lib) - 다운로드/업로드 속도, 핑<br>
패킷 및 오류 (iphlpapi.lib) - 수신/송신 패킷 수, 수신/송신 오류 수, 패킷 손실<br>
연결 상태 (iphlpapi.lib) - tcp/udp 연결 수<br>
프로세스별 네트워크 사용량 (iphlpapi.lib, psapi.lib)<br>
